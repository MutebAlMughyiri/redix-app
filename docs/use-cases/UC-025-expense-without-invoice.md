# UC-025: Save an expense without an invoice (retired)

**Retired:** 7 November 2026, by redix-api #96 "Simple expense" (D3).

Every expense's file is optional now, so the **بدون فاتورة** switch, its reason and `withoutInvoiceKey` are gone: an expense with no file is sent as it is. A deduction says why in its notes (D14).
