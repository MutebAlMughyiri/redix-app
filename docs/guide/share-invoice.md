# Sharing an invoice · مشاركة فاتورة

## English

**What it is for:** an invoice that reached you in WhatsApp, the gallery or email. Share it to REDIX to put it on an expense you entered without one, or to start a new expense with it.

**Who sees it:** whoever enters expenses. Field staff see only their own expenses.

1. Share the picture or PDF and pick **REDIX**. Sign in if asked; the file waits.
2. Choose the project if you have more than one, then **Purchases** or **Contractor payments**, then the item.
3. Choose the expense. If the invoice has a QR code, the one that matches is marked **Matching** and already chosen.
4. Tap **Attach to the chosen expense**.

Only the file goes on the expense: an approved one stays approved. The screen says if the amount or the supplier differs from the QR code. The same file cannot go on two expenses.

**New expense with this invoice** opens the expense form with the file and what its QR code says.

## العربية

**الغرض:** فاتورة وصلتك في واتساب أو المعرض أو البريد. شاركها إلى REDIX لتضعها على مصروف أدخلته بلا فاتورة، أو لتبدأ بها مصروفاً جديداً.

**من يراها:** من يُدخل المصروفات. ويرى المشرف الميداني مصروفاته فقط.

1. شارك الصورة أو ملف PDF واختر **REDIX**. سجّل الدخول إن طُلب منك؛ الملف ينتظر.
2. اختر المشروع إن كان لديك أكثر من مشروع، ثم **مشتريات** أو **دفعات مقاولين**، ثم البند.
3. اختر المصروف. إن كان في الفاتورة رمز QR، يظهر المطابق بعلامة **مطابق** ومحدداً.
4. اضغط **إرفاق بالمصروف المحدد**.

لا يُضاف إلى المصروف إلا الملف: ويبقى المعتمد معتمداً. وتقول الشاشة إن اختلف المبلغ أو المورد عمّا في رمز QR. ولا يُرفق الملف نفسه بمصروفين.

**مصروف جديد بهذه الفاتورة** يفتح نموذج المصروف بالملف وبما في رمز QR.
