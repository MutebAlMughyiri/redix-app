# Load the project file · تحميل ملف المشروع

## English

**What it is for:** bringing a project that lived in Excel into REDIX in one step, from its JSON file: its missing tables, every entry, the actual balances and its last report.
**Who sees it:** the manager who created the project, from **Load the project file** in the project's settings on its home. Anyone without «إدارة المشروع», a closed project, and a project that already holds an entry see it gray.

| To | Do |
| --- | --- |
| Load the file | Tap **Load the project file**, choose the `.json` in the phone's files, read the question, then tap **Load the project file**. |
| See what was loaded | The bar says how many entries in how many tables, the actual balances, and the report's number. The button then turns gray: a file loads once. |
| Fix refused rows | Nothing was saved. The list shows each row refused by its item, its table and its «#» in the sheet, and why. Fix those rows in the file, then load it again. |

The entries are recorded and approved in your name, each on its own date; the report is the file's, with its number, so the next one follows it.

![The question](images/project-file-confirm.png) ![Loaded](images/project-file-loaded.png) ![Refused rows](images/project-file-refused.png)

| Message | Meaning |
| --- | --- |
| This is not a REDIX project file. | The file chosen is another file. |
| The file is from a newer version of REDIX. | Update the app's server first. |
| The project already holds entries, so no file can be loaded into it. | A file loads only into a project with no entry. |

## العربية

**الغرض:** إدخال مشروع كان في Excel إلى REDIX دفعة واحدة من ملفه بصيغة JSON: جداوله الناقصة، وكل قيوده، وأرصدته الفعلية، وآخر تقاريره.
**من يراه:** مدير المشروع الذي أنشأه، من **تحميل ملف المشروع** في إعدادات المشروع على رئيسيته. ويراه رمادياً من ليست له «إدارة المشروع»، وفي المشروع المغلق، وفي المشروع الذي فيه قيود.

| لكي | افعل |
| --- | --- |
| تحمّل الملف | اضغط **تحميل ملف المشروع**، واختر ملف `.json` من ملفات الجوال، واقرأ السؤال، ثم اضغط **تحميل ملف المشروع**. |
| ترى ما حُمّل | يقول الشريط كم قيداً في كم جدولاً، والأرصدة الفعلية، ورقم التقرير. ثم يصير الزر رمادياً: يُحمّل الملف مرة واحدة. |
| تصحّح الأسطر المرفوضة | لم يُحفظ شيء. تعرض القائمة كل سطر رُفض ببنده وجدوله ورقمه «#» في الورقة، وسبب رفضه. صحّح هذه الأسطر في الملف ثم حمّله مرة أخرى. |

تُسجَّل القيود وتُعتمد باسمك، كلٌّ بتاريخه، والتقرير هو تقرير الملف برقمه، فيليه التقرير التالي.

| الرسالة | معناها |
| --- | --- |
| هذا ليس ملف مشروع من REDIX. | الملف المختار ملف آخر. |
| الملف من إصدار أحدث من REDIX. | حدّث خادم التطبيق أولاً. |
| في المشروع قيود، فلا يُحمّل فيه ملف. | لا يُحمّل ملف إلا في مشروع بلا قيود. |
