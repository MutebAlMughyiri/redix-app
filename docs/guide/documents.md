# Documents · المستندات

## English

**What it is for:** keeping a project's papers with it: drawings, permits, quantities, any file under 25 MB.
**Who sees it:** everyone in the project, from **Documents** on the project's home. Whoever manages the project adds and removes documents while it is open; anyone else sees **Add a document** gray.

| To | Do |
| --- | --- |
| Add a document | Tap **Add a document**, type its name, choose a group if you want one, then **Choose the file** and tap **Keep**. |
| Open a document | Tap it. A picture opens to zoom into; any other file goes to the phone's own app, under its own name. |
| Download a document | Tap **Download** on its row; it lands in the phone's Download folder. |
| Remove a document | Swipe its row from the edge with the red bar. It asks in the row: tap **Remove** to confirm, or **Cancel**. A row with no red bar cannot be removed by you. |

Documents in no group come first; each group follows under its name. A closed project keeps its documents to read, with nothing to add or remove.

| Message | Meaning |
| --- | --- |
| Choose the document's file first. | No file was chosen. |
| A document must be smaller than 25 MB. | The file is too big. |
| Give the document a name, in 200 letters at most. | The name is empty or too long. |

## العربية

**الغرض:** حفظ أوراق المشروع معه: المخططات والتصاريح والكميات وأي ملف أصغر من 25 ميغابايت.
**من يراها:** كل من في المشروع، من **المستندات** في رئيسية المشروع. ويضيف المستندات ويحذفها من يدير المشروع ما دام مفتوحاً، ويرى غيره **إضافة مستند** رمادياً.

| لكي | افعل |
| --- | --- |
| تضيف مستنداً | اضغط **إضافة مستند**، واكتب اسمه، واختر تصنيفاً إن أردت، ثم **اختر الملف** واضغط **حفظ**. |
| تفتح مستنداً | اضغط عليه. تُفتح الصورة للتكبير، ويذهب أي ملف آخر إلى تطبيق الجوال باسمه. |
| تنزّل مستنداً | اضغط **تنزيل** في صفه؛ فيُحفظ في مجلد التنزيلات في الجوال. |
| تحذف مستنداً | اسحب صفه من جهة الشريط الأحمر. لا سؤال. الصف الذي لا شريط فيه لا يمكنك حذفه. |

تأتي المستندات التي بلا تصنيف أولاً، ثم كل تصنيف تحت اسمه. ويبقى للمشروع المغلق مستنداته للقراءة، بلا إضافة ولا حذف.

| الرسالة | معناها |
| --- | --- |
| اختر ملف المستند أولاً. | لم يُختر ملف. |
| يجب أن يكون المستند أصغر من 25 ميغابايت. | الملف كبير. |
| اكتب اسم المستند في 200 حرف على الأكثر. | الاسم فارغ أو طويل. |
